# Contour4 Valuables

Девять предметов для карты «Контур-4» в R.E.P.O. 0.5.2. Предметы размещает карта. Штатная случайная добыча игры остаётся прежней.

## Установка

Скачайте [Contour4 Valuables 0.2.3](https://github.com/Karikatun/contour4-valuables/releases/tag/v0.2.3) и [карту 0.2.18](https://github.com/Karikatun/contour4/releases/tag/v0.2.18). Установите оба ZIP в один профиль с BepInExPack 5.4.2305 и REPOLib 4.5.1. Для ручной установки скопируйте папки из каталога plugins каждого ZIP в BepInEx/plugins игры.

Сборка предназначена для предварительного тестирования. Проверки игровых сценариев и мультиплеера для этой версии остаются открытыми.

## Исходники

C#-плагин находится в Plugin/, редактируемые модели — в Native/. Проект Unity/ рассчитан на Unity 6000.3.17f1. Для выпуска пакета tools/build.ps1 читает отчёты Unity о проверках префабов и бандла. Их нужно сгенерировать локально. Для компиляции нужны DLL установленной игры и её модов.

Сердечник поля создан с помощью [Meshy](https://www.meshy.ai/) и адаптирован для «Контура-4». Условия использования определяются происхождением модели и [условиями Meshy](https://www.meshy.ai/terms-of-use).
