# Лицензии на материалы

## Сердечник поля (`field-core`)

Исходная модель **Industrial Generator** была создана с помощью Meshy. Для «Контура-4» модель прошла ретопологию, запекание текстур и равномерное масштабирование под габарит игрового предмета.

Редактируемая модель находится в `Native/11-field-core.blend`, материалы для Unity — в `Unity/Assets/Source/11-field-core/`. Готовый предмет входит в бандл `contour4-valuables.bundle`.

Тариф Meshy на момент генерации и лицензия конкретной модели не подтверждены. Права на исходную модель определяются применимыми условиями Meshy. Условия для пользователей разных тарифов описаны в разделе 3.2, а условия публикации в Meshy Community — в разделе 3.3. [Условия использования Meshy](https://www.meshy.ai/terms-of-use)

## Криостат (`anomaly-cryostat`)

Модель подготовлена для «Контура-4» в Blender. Для части текстур корпуса использованы образцы материалов из FBX, созданного с помощью Meshy и предоставленного владельцем проекта. Редактируемая модель находится в `Native/10-anomaly-cryostat.blend`, а материалы для Unity — в `Unity/Assets/Source/10-anomaly-cryostat/`. Условия использования донорских материалов определяются [условиями Meshy](https://www.meshy.ai/terms-of-use).
